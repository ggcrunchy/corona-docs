## Overview

WIP WIP WIPEE

Computes the [matrix][native.C.CoronaGraphics.CoronaMatrix4x4] product `result = m1 * m2`.

## Syntax

``````c
void CoronaMultiplyMatrix4x4( const CoronaMatrix4x4 m1, const CoronaMatrix4x4 m2, CoronaMatrix4x4 result );
``````

##### m1
Left-hand matrix.

##### m2
Right-hand matrix.

##### result
Out parameter: receives the product of `m1` and `m2`.
