## Overview

WIP WIP WIPEE

Extensions allow more attributes to be supplied through [shapes][api.type.ShapeObject]
and [lines][api.type.LineObject].

Display objects that have been extended in this way can thus take advantage of effects
that rely on [vertex extensions][api.library.graphics.defineVertexExtension].
